تحديث مشروع إنجازي — معايير المعلم/المعلمة وربط الشواهد ببنود المتابعة

محتويات التحديث:
1) استبدال البنود التجريبية للمعايير الـ11 في مسار المعلم/المعلمة بالنصوص المستخرجة من صور المستخدم، وعددها 76 بندًا.
2) تحديث بيانات التهيئة في migration الأساسية 0000 لتكون متطابقة عند إنشاء قاعدة جديدة.
3) إضافة migration 0007 لتحديث المعايير المنشورة لمسار المعلم/المعلمة فقط. لا تغيّر معايير المسارات الأخرى، ولا تحذف سجلات الشواهد أو التقدم.
4) إضافة ربط الشاهد ببند المتابعة عبر indicator_index وindicator_text في migration 0006.
5) إتاحة اختيار بند لكل ملف عند الرفع، وتعديل الربط لاحقًا من محرر الشاهد.
6) عرض الشواهد تحت بندها في صفحة المعيار، مع إبقاء الشواهد القديمة غير المرتبطة ظاهرة.
7) تجميع الشواهد في PDF تحت المعيار والبند، وعدم عرض عنوان الشاهد الذي أدخله المستخدم.
8) إضافة/تحديث اختبارات رفع وربط الشواهد وتصدير PDF.

تنبيه مهم:
- هذه الحزمة ملفات مصدر فقط، وليست نشرًا للموقع.
- لم يتم الاتصال بـCodespaces أو GitHub مباشرة.
- لم يتم تطبيق أي migration على قاعدة بيانات حية أو تطويرية.
- يجب مراجعة migrations 0006 و0007 قبل تطبيقهما على قاعدة اختبار.
- تعذر تشغيل الاختبارات والبناء في بيئة إعداد الحزمة لعدم وجود node_modules، ومحاولات npx انتهت بمهلة؛ لذلك لا توجد نتائج اختبار ناجحة مؤكدة في هذه الجلسة.

طريقة الاستخدام:
1) فك الحزمة في جذر مستودع المشروع مع الحفاظ على المسارات.
2) راجع التغييرات ثم شغّل npm ci.
3) شغّل npx vitest run وnpx tsc --noEmit وnpm run build.
4) طبّق migrations على قاعدة اختبار فقط بعد مراجعتها، ثم اختبر رفع شاهد وربطه ببند وتصدير PDF.
5) لا تطبق على قاعدة الإنتاج ولا تنشر قبل الموافقة الصريحة.
