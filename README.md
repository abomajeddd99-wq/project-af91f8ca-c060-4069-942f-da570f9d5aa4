# إنجازي للمعلم

Build a professional Arabic RTL responsive web application named إنجازي for Saudi teachers. Use a modern minimalist design with teal, white, and soft cream colors. Create a landing page, email registration and login, a private teacher dashboard, teacher profiles, performance standards management, evidence uploads with images and PDF files, completion tracking, and printable Arabic PDF portfolios. Use the built-in backend for authentication, database and private file storage. Every teacher must access only their own records using enforced row-level security and private storage access policies. Include an admin role for managing standards without exposing teachers' private files. Design for mobile first. Start with a functional MVP using sample standards clearly marked as placeholders until official Saudi standards are supplied. Do not publish until security and multi-user isolation tests pass.
