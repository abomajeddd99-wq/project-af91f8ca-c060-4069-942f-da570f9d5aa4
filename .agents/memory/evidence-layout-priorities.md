Evidence pagination is adaptive, not mandatory: legibility takes precedence over reaching the teacher's selected maximum. Teachers can select one, two, three, or four images per page globally or per standard; the default is two. Four uses a strict RTL 2×2 grid. Single-image pages retain approximately one-third-page image height.

**Why:** The user replaced the earlier fixed maximum of two with teacher-controlled layouts, while retaining concise captions immediately beneath each image and overflow safeguards.

**How to apply:** Preserve this priority during future PDF refinements. A4 portrait applies to generated pages only; never rotate, resize, crop, or overlay original uploaded PDF pages to enforce it.

Preview and export must consume the same measured, numbered page plan. Layout preferences are browser-local, not changes to teacher records.

**Why:** Teachers need immediate, accurate layout feedback without changing production data or the database schema.

**How to apply:** Keep layout calculation and page numbering shared; do not reintroduce independent preview-only pagination.

Every standard now requires its own dedicated portrait cover, immediately followed by that standard's evidence. Do not restore the former optimization that combined short standards on shared pages.

**Why:** The user explicitly replaced compact standard introductions with individual royal-style covers, while retaining adaptive evidence pagination.

Do not treat the current main portfolio cover as the approved official educational cover. Identify the exact approved reference, or request confirmation before replacing it. Do not invent missing CV details, Saudi educational objectives, or authorization to use an official logo.

**Why:** The user explicitly rejected the current first page as not matching the previously approved Ministry-of-Education-inspired cover and required reference confirmation rather than a new assumed design.

**How to apply:** Distinguish the main cover from the dedicated standard covers. Obtain the missing approved cover, CV reference, and supplied objectives before making reference-dependent refinements.
